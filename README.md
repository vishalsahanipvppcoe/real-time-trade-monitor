# Arham Insurance Brokers Pvt. Ltd. — Fintech Engineering Assessment

## Project Overview
Real-time trade reporting dashboard and asynchronous trade data ingestion engine simulating a long-running Bombay Stock Exchange (BSE) trade pull operation with Server-Sent Events (SSE).

## Intended Architecture & Stack
- **Backend**: Node.js & Express REST API with Server-Sent Events (SSE)
- **Frontend**: React Single-Page Application (Vite)
- **Data Model**: Deterministic seeded mock BSE trade records
- **Environment**: Node.js v24.20.0, npm 11.19.0, Windows PowerShell
